[RemNote](https://www.remnote.com) theme inspired by the [System76 COSMIC](https://system76.com/cosmic) desktop. Charcoal workspaces and soft-white paper, with a purposeful spectrum of accents in both light and dark modes.

| Accent | Desktop pigment | Role |
| --- | --- | --- |
| Solar yellow | `#ffbe00` | Primary actions, checked controls, clozes |
| Coral orange | `#ff8859` | Study counters, effort ratings, warnings |
| Cyan blue | `#62b8ce` | References, portals, table headers, keyboard focus |
| Lavender | `#bd89ed` | Tags, selected navigation, quote borders |

Dark mode uses a `#2c2c2c` canvas with recessed charcoal navigation and raised neutral controls. Light mode uses a `#fafaf9` canvas and soft gray chrome; accent text uses deeper companion shades for readability. Colors are inspired by the supplied desktop screenshot, not an official COSMIC token export. Highlights remain translucent, and destructive/success feedback retains its semantic colors.

Solar gradients wash primary actions from yellow into coral. Thin lavender–periwinkle–cyan ribbons trace pane headers and account capsules, while colored inset edges distinguish tags, portals and code. The composition concentrates color at interaction points and keeps long-form reading surfaces quiet.

Version **0.4.0**. The release ID remains `cosmic-dark`; the package supports both modes automatically. Upload `releases/cosmic-0.4.0.zip` from this repository to RemNote. Disable other theme CSS and browser recoloring extensions such as Dark Reader when evaluating the palette. Development instructions: https://github.com/leowajda/remnote/blob/refactor/cosmic-development/themes/cosmic/dev/README.md

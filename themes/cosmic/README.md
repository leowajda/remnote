# COSMIC for RemNote

A quiet workspace in charcoal, graphite and ice cyan. One clear interaction accent, readable controls, and considered light and dark modes. Your note highlights and meaningful status colors stay intact.

Version **0.5.0**. Install [`cosmic-0.5.0.zip`](https://github.com/leowajda/remnote/blob/fix/cosmic-native-palette/releases/cosmic-0.5.0.zip). The release ID remains `cosmic-dark` for existing installations.

PDF controls and excerpts follow the theme; page appearance is controlled by RemNote's PDF preference. [Development and testing](https://github.com/leowajda/remnote/blob/master/themes/cosmic/dev/README.md).
